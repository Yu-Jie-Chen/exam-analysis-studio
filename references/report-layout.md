# 报告版式与字数约束

版式在 `vendor/final_report.py` 里写死，坐标是绝对坐标；模板按"写满"设计，
每个区块都留了 3–5 行的位置。**文字放不下会抛错，不会自动缩字号**——按提示精简，
不要改模板；也不要交一份每块只有两行、周围全是白的报告。

## 五页怎么排

```text
p1  封面        logo / 试卷分析报告 / 学生 学校 年级 学科 考试 报告日期
p2  诊断        ┌ 01 这次考得怎么样 ┐ ┌ 02 各类题拿了多少分 ┐
                │ 得分 满分 得分率 仪表盘 │ │ 每类：得分/占比/条 + 点评 │
                │ 优势 3 行 + 满分题清单   │ │                          │
                │ 短板 3 行 + 失分最重     │ │                          │
                │ 本轮先拿回 N 分          │ │                          │
                └ 03 失分结构 ┘         └ 04 做得好的地方 ┘
                  环形图 + 分题型失分条      优势 + 得分最稳 6 题表
                  + 一句结构判断              + 短板 + 改法提示
p3  问题与规划  ┌ 05 哪些地方丢了分，怎么改（2×2，≤4 题）┐
                │ 每题四行：原答 / 卡点 / 怎么练 / 验收   │
                ├ 06 近期怎么复习（三栏，各 4–5 行）+ 节奏 ┤
                ├ 07 诊断反馈：问题出在哪儿 / 接下来怎么做 ┤
p4+ 附件 A/B…   每题：原答 → 对照 → 参考结果 → 先看哪里 → 关键解法 → 顺序 → 验收
```

页脚 `文源教育 · 试卷分析报告 · <analysisDate>` 与 `NN / NN` 从第 2 页开始，
由 PyMuPDF 合成——所以五页版必须装 PyMuPDF。

## 硬约束

| 位置 | 约束 | 超了会怎样 |
|---|---|---|
| 题型（`type` 的类别数） | **≤6** | `ValueError: 最终模板的题型最多展示6类` |
| `strengthText` / `weaknessText` | ≤75 字（约 3 行） | 报「优势短摘要」/「薄弱短摘要」 |
| `directionText` | ≤50 字（约 2 行） | 报「学习方向短摘要」 |
| `planFirst` / `planNext` / `planLater` | ≤110 字（约 4–5 行） | 报「优先处理安排」类错误 |
| `problemText` | ≤120 字（约 3 行） | 报「诊断反馈·问题」 |
| `nextStepText` | ≤150 字（约 3–4 行） | 报「诊断反馈·做法」 |
| `appendixIds` | ≤5 题、不重复、必须存在 | `ValueError: 附件题号须存在且不重复，最多5题` |
| 封面 `school` / `exam` | 单行约 26 个汉字 | 报「封面学校：」/「封面考试：」 |
| 第 3 页每题 | `digest*` 三句各 20–45 字、`acceptance` ≤60 字 | 报「第 N 题原答 / 验收」 |
| 题型点评 `typeComments` | 每条 1–2 行（宽度 233 pt） | 报「<题型>题型说明」 |

字数上限是经验的；真正的判据是渲染有没有报错。**写满，但别硬凑**：不够就补题号、
分数、步骤这些证据，不要加"要努力""多练习"这类空话。

## 每块怎么写才不空

| 块 | 写什么 | 大概行数 |
|---|---|---|
| 01 优势 / 04 优势 | 先结论（哪几题满分、哪种题型/能力稳），再给证据（题号、得分率） | 3 行 |
| 01 短板 / 04 短板 | 失分集中在哪几题（题号 + 失分），卡在哪一步 | 3 行 |
| `directionText` | 一句"先…再…最后…"，带题号，能直接排课 | 2 行 |
| 05 每题 | 原答指到答题卡哪一行；卡点写"会到哪一步"；怎么练给顺序和数量；验写给"做到什么算过" | 4 行 |
| 06 三栏 | 每栏"做什么 + 做多少 + 做到什么程度"，有题号、有次数 | 各 4–5 行 |
| 07 问题出在哪儿 | 先给判断（不是不会，是卡在哪一步），再落到题号与失分：哪题丢几分、丢在哪个断点上 | 3 行 |
| 07 接下来怎么做 | 编号列动作：改哪题、按什么步骤、做几次、什么时候交；最后给一句"怎么算过关" | 3–4 行 |

自动补位（不用模型写）：01 会列出满分题号与"本轮先拿回 N 分"，03 会写一句失分结构
判断，04 会列出得分最稳的 6 道题，06 会补"节奏"一行，07 会补"下次课先查哪几题"一行。
这些是数据的投影，不要和 `strengthText` / `weaknessText` 写重复。

## 第 3 页为什么最容易爆

05 四道题按 2×2 排，每题只有约 131 pt：标题 1 行 + 四行正文。一行 8.7 pt 约 55–58 字，
所以 `digestEvidence` / `digestMastery` / `digestAction` 各控制在 **20–45 字**，
`acceptance` 控制在 **60 字以内**。完整表述留在 `cause` / `action` 里。

只有 3 题时 05 会改成整宽三块，每块更高；写长一点没问题。

## 附件怎么选

1. `appendixIds` 有值 → 按写的顺序取，每题一页起。
2. 留空 → 按 `priority` 降序、失分从多到少取前 2 题。
3. 每题的内容顺序固定：学生原始作答 → 作答对照与问题定位 → 参考结果 → 这道题先看哪里
   → 关键解法 → 下次遇到这类题按这个顺序做 →（可选）自主练习 → 验收要求。
4. `practiceQuestion` 只有真实存在才填；编一道"配套练习"是最常见的越界。

## 其它交付格式

| `--format` | 页数 | 用途 | 额外依赖 |
|---|---|---|---|
| `final`（默认） | 5+ | 正式交付的五页品牌报告 | PyMuPDF |
| `poster` | 1 | 原单页补充报告（PDF / SVG / DOCX） | `--docx` 需要 python-docx |
| `compact` | 1–2 | 两页家长版，Word 可改 | 同上 |
| `detail` | 多 | A2 逐题题号清单 | reportlab |
| `paper` | 多 | B2 纸质复做记录 | reportlab |
| `acceptance` | 1 | 内部交付验收记录 | reportlab |

两页家长版与单页版用的字体是 reportlab 自带的 `STSong-Light`，不依赖品牌字体。

## 排错表

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `「优势短摘要」文字超出最终模板区域` | `strengthText` 太长 | 砍到 75 字以内，细节移到逐题 `cause` |
| `「诊断反馈·问题」文字超出…` | `problemText` 太长 | 砍到 120 字以内，细节移到逐题的 `cause` |
| `「诊断反馈·做法」文字超出…` | `nextStepText` 太长 | 砍到 150 字以内，只留动作、次数、期限 |
| `最终模板的题型最多展示6类` | 题型命名太碎 | 合并同类（"单选/多选"→"选择题"），别删题 |
| 第 3 页某题只剩标题没有内容 | 三句摘要都没填 | 补 `digest*` 三个短句 |
| 页脚没有页码 / 只有 3 页 | 没装 PyMuPDF | `pip install PyMuPDF`，或 `--python` 指定装好的解释器 |
| 封面上学校名被截断 | 单行放不下 | 写简称，全称放 `materialNotes` |
| 报告里分数全是"待核" | `reviewed` 还是 `false` | 老师看过分析稿后 `run.py approve` |
| 某块只有两行、下面一大片白 | 文案太短 | 按上表补到 3–5 行；补证据，不要加套话 |

## 改版式的正确姿势

1. 改教学工作台里的 `final_report.py`；
2. `python scripts/sync_engine.py --workbench <教学工作台目录>`；
3. `python scripts/run.py render <work> --preview` 复核；
4. 更新本文件的约束表。

直接改 `vendor/` 会让两份代码分叉，下次同步就丢。
