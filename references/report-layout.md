# 报告版式与字数约束

版式在 `vendor/final_report.py` 里写死，坐标是绝对坐标。**文字放不下会抛错，不会自动缩字号**
——错误信息里带着哪一段放不下，按提示精简文案，不要改模板。

## 五页怎么排

```text
p1  封面        logo / 试卷分析报告 / 学生 学校 年级 学科 考试 报告日期
p2  诊断        ┌ 01 这次考得怎么样 ┐ ┌ 02 各类题拿了多少分 ┐
                └ 03 失分去哪了     ┘ └ 04 做得好的地方     ┘
p3  问题与规划  ┌ 05 哪些地方丢了分，怎么改（≤4 题）┐
                ┌ 06 近期怎么复习（三栏）          ┐
                ┌ 07 老师怎么沟通、家长怎么配合    ┐
p4+ 附件 A/B…   每题：原答 → 对照 → 参考结果 → 先看哪里 → 关键解法 → 顺序 → 验收
```

页脚 `文源教育 · 试卷分析报告 · <analysisDate>` 与 `NN / NN` 从第 2 页开始，
由 PyMuPDF 合成——所以五页版必须装 PyMuPDF。

## 硬约束

| 位置 | 约束 | 超了会怎样 |
|---|---|---|
| 题型（`type` 的类别数） | **≤6** | `ValueError: 最终模板的题型最多展示6类` |
| `strengthText` / `weaknessText` / `directionText` | ≤60 字 | 绿色/红色框放不下，报「优势短摘要」类错误 |
| `planFirst` / `planNext` / `planLater` | ≤100 字 | 三栏之一溢出，报「优先处理安排」类错误 |
| `teacherCommunication` | ≈90 字（3 行） | 报「老师沟通安排」 |
| `parentSupport` | ≈60 字（2 行） | 报「家长配合说明」 |
| `appendixIds` | ≤5 题、不重复、必须存在 | `ValueError: 附件题号须存在且不重复，最多5题` |
| 封面 `school` / `exam` | 单行约 26 个汉字 | 报「封面学校：」/「封面考试：」 |
| 第 3 页每题诊断 | 三句合计约 130 字、≤4 行 | 报「第 N 题诊断短摘要」 |
| 题型点评 `typeComments` | 每条 1–2 行（宽度 233 pt） | 报「<题型>题型说明」 |

字数上限是经验的；真正的判据是渲染有没有报错。**先写短，再看预览补。**

## 第 3 页为什么最容易爆

四道题平分 268 pt 高度，每题只剩约 47 pt：标题 1 行 + 摘要 3 行。
所以 `digestEvidence` / `digestMastery` / `digestAction` 各自控制在 **25–40 字**，
三句合起来像"电报"，不要写成完整段落。完整表述留在 `cause` / `action` 里。

## 附件怎么选

1. `appendixIds` 有值 → 按写的顺序取，每题一页起。
2. 留空 → 按 `priority` 降序、失分从多到少取前 2 题。
3. 每题的内容顺序固定：学生原始作答 → 作答对照与问题定位 → 参考结果 → 这道题先看哪里
   → 关键解法 → 下次遇到这类题按这个顺序做 →（可选）自主练习 → 验收要求。
4. `practiceQuestion` 只有真实存在才填；编一道"配套练习"是最常见的越界。

## 其它交付格式

| `--format` | 页数 | 用途 | 额外依赖 |
|---|---|---|---|
| `final`（默认） | 5+ | 正式交付的五页品牌报告 | PyMuPDF |
| `poster` | 1 | 原单页补充报告（PDF / SVG / DOCX） | `--docx` 需要 python-docx |
| `compact` | 1–2 | 两页家长版，Word 可改 | 同上 |
| `detail` | 多 | A2 逐题题号清单 | reportlab |
| `paper` | 多 | B2 纸质复做记录 | reportlab |
| `acceptance` | 1 | 内部交付验收记录 | reportlab |

两页家长版与单页版用的字体是 reportlab 自带的 `STSong-Light`，不依赖品牌字体。

## 排错表

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `「优势短摘要」文字超出最终模板区域` | `strengthText` 太长 | 砍到 60 字以内，细节移到逐题 `cause` |
| `最终模板的题型最多展示6类` | 题型命名太碎 | 合并同类（"单选/多选"→"选择题"），别删题 |
| 第 3 页某题只剩标题没有内容 | 三句摘要都没填 | 补 `digest*` 三个短句 |
| 页脚没有页码 / 只有 3 页 | 没装 PyMuPDF | `pip install PyMuPDF`，或 `--python` 指定装好的解释器 |
| 封面上学校名被截断 | 单行放不下 | 写简称，全称放 `materialNotes` |
| 报告里分数全是"待核" | `reviewed` 还是 `false` | 老师看过分析稿后 `run.py approve` |

## 改版式的正确姿势

1. 改教学工作台里的 `final_report.py`；
2. `python scripts/sync_engine.py --workbench <教学工作台目录>`；
3. `python scripts/run.py render <work> --preview` 复核；
4. 更新本文件的约束表。

直接改 `vendor/` 会让两份代码分叉，下次同步就丢。
