# 材料：要什么、缺了怎么办

## 必备与可选

| 材料 | 必需 | 用来做什么 | 没有会怎样 |
|---|---|---|---|
| 完整试卷（全部页面） | ✅ | 题干、分值、题号、配图 | 缺页 = 该页题目无法覆盖，`materialNotes` 必须写明 |
| 原始答题卡 / 答题卷 | ✅ | 原始作答、老师批改的得分 | 只能拿到"总分"，逐题分析退回猜测——此时停下问 |
| 成绩（得分、满分、班级/年级均分如有） | ✅ | 得分率、与其他题的对照 | 只有卷面得分也能做，但无法说"这次整体偏难还是偏易" |
| 参考答案 | 建议 | `referenceAnswer` | 可以自己解，但必须标 `scoringSource: "教师自拟参考解，待复核"` |
| 分项评分细则 | 建议 | `scoringPoints`、部分得分 | 只能记总分，`score` 可能不得不留 `null` |
| 学生想弄明白的题 | 可选 | 沟通时的切入点 | 由 `priority` 自己排 |

## 拍照 / 扫描

- 一页一张，**不要跨页拼接**；拍歪一点没关系，缺角不行。
- 300 万像素以上；`render_pages.py --max-width 1800` 会统一缩放。
- 答题卡的正反面都要——很多学科的解答题在背面。
- 有订正痕迹的卷子，正片（原始作答）和订正分别拍，不要叠在一起看。
- PDF 优先；扫描件如果带文字层，`--text` 可以辅助核对题干，但**原始作答必须看图**。

一次分析建议 ≤40 页（试卷 + 答题卡 + 答案合计）。超了先拆：一份报告对应一次考试。

## 缺料怎么处理

先把范围说清楚，再开做。这三种写法都可以接受：

```text
第 6 页缺失，第 15、16 题未覆盖；当前录入第 1—14 题，合计 81 分，
不代表全卷满分。缺官方答案，参考解为自拟，待教师复核。
```

处理原则：

1. **不要用"应该"补题。** 缺的题就是缺，写进 `materialNotes`。
2. **不要用总分反推逐题分。** 总分 63 分推不出第 9 题是几分。
3. **部分覆盖的报告照样能交付**，但封面/正文要能看出"本次可分析范围"。`summary`
   第一句就写范围，别把 81 分说成"整卷"。
4. 缺关键题干或答题卡时，`run.py check` 不拦你，但报告会失真——**这种情况先问用户**。

## 命名与归档

`run.py new` 会把材料复制进 `work/<id>/source/`，重名文件自动加后缀，原件不动。
`manifest.json` 记 `sha256`，以后想确认"分析的是不是这一版"就看它。

`<id>` 默认 `YYYYMMDD-学科-学生`，例如 `20261025-物理-王小明`。
一个学生一次考试一个工作目录；同一份卷子做第二轮（复做）另开一个，不要覆盖。

## 隐私

- 真实姓名只留在 `work/<id>/` 里，不进公开仓库、不进示例。
- 班级排名、学号、家长手机号**不进报告**，需要时写在学生档案里，不写进这份 PDF。
- 发到群里的截图，先把封面和姓名糊掉。
